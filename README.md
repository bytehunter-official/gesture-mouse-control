# Gesture Mouse Control
基于手部手势识别的鼠标控制工具，通过摄像头捕捉手部动作，实现鼠标移动、单击/双击/长按、滚轮滚动，以及Windows系统快捷操作（任务视图、语音输入）等功能。

## 项目介绍
本项目利用 `MediaPipe` 实现手部关键点检测，结合 `OpenCV` 处理摄像头画面，通过 `PyAutoGUI` 模拟鼠标和键盘操作，无需物理鼠标即可完成电脑基础交互。核心优势是实时性强、手势识别精准，适配Windows系统的常用快捷操作，提升无接触操作体验。

## 核心特性
- 🖱️ 鼠标控制：食指移动控制鼠标光标位置
- 🖲️ 点击操作：拇指与中指贴合实现单击/双击/长按
- �滚轮控制：特定手势实现鼠标滚轮上下滚动
- ⌨️ 系统快捷：
  - 召唤Windows任务视图（Win+Tab）
  - 开启Windows语音输入（Win+H）
- 🎯 自适应画面：自动适配摄像头画面与屏幕分辨率，优化光标映射精度

## 技术栈
- Python 3.8+
- OpenCV：摄像头画面采集与处理
- MediaPipe：手部关键点检测
- PyAutoGUI：模拟鼠标/键盘操作
- NumPy：数值计算与坐标归一化

## 快速开始
### 前置条件
- 安装Python 3.8及以上版本
- 确保电脑配备可用的摄像头（内置/外置均可）
- Windows系统（因依赖Win快捷键，暂不支持macOS/Linux）

### 安装依赖
```bash
# 克隆仓库
git clone https://github.com/你的用户名/gesture-mouse-control.git
cd gesture-mouse-control

# 安装所需依赖
pip install opencv-python mediapipe pyautogui numpy
```

### 运行项目
```bash
python gesture_recognation.py
```

### 退出程序
在摄像头窗口中按下键盘 `q` 键即可退出。

## 手势操作指南
| 手势动作 | 对应功能 | 操作细节 |
|----------|----------|----------|
| 食指伸直移动 | 控制鼠标光标移动 | 画面中蓝色矩形为有效控制区域，食指在该区域内移动即可同步控制光标 |
| 大拇指和中指第二关节触碰后松开 | 鼠标单击 | 触碰后松开手势立即触发单击 |
| 大拇指和中指第二关节连续触碰2次 | 鼠标双击 | 短时间内完成两次触碰+松开动作触发 |
| 大拇指和中指第二关节触碰保持5秒以上 | 鼠标长按 | 持续触碰5秒触发长按，松开手势即释放长按状态 |
| 比耶手势 + 大拇指指尖触碰无名指指尖 | 鼠标滚轮向下滚动 | 比耶（食指+中指伸直）基础上，拇指指尖碰无名指指尖触发下滚 |
| 比耶手势 + 大拇指指尖触碰无名指第二关节 | 鼠标滚轮向上滚动 | 比耶（食指+中指伸直）基础上，拇指指尖碰无名指第二关节触发上滚 |
| 三指伸直 + 大拇指与小拇指指尖触碰 | 切换窗口（Win+Tab） | 中指+无名指+小指伸直，拇指指尖碰小拇指指尖触发任务视图 |
| 我爱你手势 | 语音输入（计算机听写） | 触发 Win+H 快捷键，开启系统语音听写功能 |
| 摄像头窗口顶层时按Q键（英文输入法） | 退出程序 | 需确保摄像头窗口为当前活动窗口，英文输入法下按Q键退出 |
### 提示
1. 所有触碰类手势需精准触碰到指定关节/指尖位置，否则可能无法触发对应功能；
2. 时长类手势（长按）需保持触碰状态达到指定时间（5秒），松开后才会结束对应状态；
3. 退出程序的按键操作有明确的前置条件（窗口顶层+英文输入法），需满足后再执行。

## 注意事项
1. 运行时确保手部在摄像头清晰可见范围内，避免强光/逆光影响识别
2. 首次运行可能因PyAutoGUI权限问题报错，需允许Python访问摄像头/输入设备
3. 蓝色矩形区域是光标映射的有效区域，尽量在该区域内操作以提升精度
4. 若识别不灵敏，可调整代码中 `click_threshold`、`long_press_duration` 等参数

## 常见问题
- Q：光标移动不精准？
  A：调整摄像头角度，确保手部在蓝色矩形中心区域，或修改 `rect_w`/`rect_h` 调整映射区域大小。
- Q：手势识别无响应？
  A：检查摄像头是否被占用，或提高 `min_detection_confidence` 阈值（默认0.9）。
- Q：快捷键无效？
  A：确认系统为Windows，且Win键未被其他软件占用。
